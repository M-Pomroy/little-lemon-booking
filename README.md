# Little Lemon Booking App

This project was developed as part of the [Meta Front-End Developer Professional Certificate](https://www.coursera.org/professional-certificates/meta-front-end-developer) undertaken in 2025. It was developed using React and includes unit tests for the form functionality, written using the react testing library.

## Scenario

The owners of Little Lemon learn that their customers are frustrated that they can't easily reserve a table on their website. The want to resolve this issue so that they can plan staff and supplies, not solely rely on walk-ins, and give their diners a great experience.
